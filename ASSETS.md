# Asset provenance

Every binary that ships in this mod, and where it came from.

The rule: **nothing enters this repository without a row here naming a source and a licence that
permits redistribution under MIT.** A file whose provenance cannot be stated does not go in the
tree. It gets regenerated or replaced instead. Code follows the same rule in
`THIRD-PARTY-NOTICES.md`.

## Every row is stated

Four of the five images are the author's own: one drawn icon, reused at three sizes and paths. The
fifth, the settings cog, is machine-generated.

That one is enough to require Modrinth's **AI-generated content** disclosure with **assets** ticked,
independently of anything about the code. Disclosure is all it requires: the cog ships inside the jar
as an in-game texture, not as project-page imagery, so the prohibition below does not reach it.

## Publishing note: the icon and the platform rules are a separate question

Everything above is settled for licensing. All of it is the owner's to redistribute under MIT.
Distribution platforms ask a different question, and it has a different answer.

Modrinth's rules prohibit imagery on a project page that was *"created or derived from generative AI
output"*, covering the icon, banner, gallery and description. That is a prohibition, not a
disclosure requirement, so declaring the origin does not satisfy it.

The icon was drawn by the owner and then colour-passed through an image model. Whether that counts
as "derived from generative AI output" is Modrinth's call, and the wording reads as though it does.
An icon with no model anywhere in its pipeline avoids the question. Gallery screenshots are
unaffected: those are captures of the running game.
